PINK ROMANTIC BIRTHDAY SURPRISE

Files:
- index.html  : Page content and structure
- style.css   : Pink romantic design, cake illustration, and animations
- script.js   : Welcome button, candle interaction, confetti, hearts, letter modal, and replay

HOW TO RUN
1. Extract the ZIP file.
2. Open the pink-romantic-birthday folder in VS Code.
3. Open index.html in your browser, or use the Live Server extension.

PERSONALIZE THE PAGE
Open index.html and edit these sample messages:
- "Hey, birthday girl!" on the welcome screen
- "my beautiful girl" in the main birthday heading
- The paragraphs inside the section with class="letter-body"
- The sign-off inside class="letter-signoff"

You can replace "someone who adores you" with your name or nickname.

TIP
The cake and candle are made with HTML and CSS, so no image assets are required.
